# 记账本 - 微信小程序

简洁实用的微信小程序记账工具，支持收入/支出记录、月度账单、分类统计、多币种、存钱计划和汇率换算。

---

## 🚀 快速开始

1. 微信开发者工具 → **项目 → 导入项目**
2. 选择 `D:\Claude-Workspace\ledger-miniapp`
3. AppID 填入你的小程序 AppID（测试可点"使用测试号"）
4. 编译运行

---

## 📱 功能说明

### 1. 账单（首页）
- 按月切换，查看收入/支出/结余总额
- 存钱计划快捷卡片，显示总进度
- 按日分组，显示星期 + 每日收支小计
- 每条记录带 emoji 分类图标 + 币种
- 长按记录可删除
- 花费提醒横幅（当月超支时弹出）

### 2. 记账
- 支出/收入切换，UI 颜色跟随变化
- **多币种支持**：可切换 8 种货币，金额前显示对应符号
- emoji 分类图标，选中高亮
- 金额校验（>0、<1 亿）
- 日期选择 + 备注

### 3. 统计
- **分类排行**：每个分类显示金额、占比、进度条
- **每日趋势**：Canvas 直方图，日均/最高/合计
- **点击分类** → 弹出明细，显示每条记录（含币种）
- 支持按月切换

### 4. 设置
- 头像选择 + 昵称设置
- **存钱计划入口**：7 种存钱方法
- **货币设置**：多币种开关、默认货币、显示符号
- **汇率换算器**：8 种货币实时互转
- 收支分类管理与保存
- 数据导出（JSON）和清空

### 5. 存钱计划
- 7 种方法：灵活存钱、365 天、52 周（正向/逆向）、定额、12 存单、36 存单
- 自动计算各期金额和总额
- 进度条可视化，存入时自动同步记账
- 首页快捷进度卡片
